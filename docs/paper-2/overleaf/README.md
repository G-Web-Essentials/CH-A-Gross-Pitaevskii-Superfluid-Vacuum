## Overleaf settings

1. **Menu → Settings → Compiler:** **pdfLaTeX + Biber** (not BibTeX).
2. **Main document:** `main.tex`.
3. If compile fails with `\abx@aux@refcontext` or stale `output.aux` errors:
   - delete any stray `output.pdf` in the project root (rename if you uploaded one by mistake);
   - **Menu → Logs and output files → Other logs & files → Clear cached files**;
   - recompile (pdfLaTeX → Biber → pdfLaTeX ×2).

`main.tex` uses `biblatex` + `references.bib` — do **not** use pdfLaTeX-only mode.

## Local build

```bash
cd docs/paper-2/overleaf
pdflatex main
biber main
pdflatex main
pdflatex main
```

Requires TeX Live with `biblatex-biber`.  
`main.tex` uses `\graphicspath{{figures/}}` — compile from the `overleaf/` directory.
